# 烧写好系统后对开发板的额外配置

1. 参考`rk3566核心板+底板usb配置.md`配置usb相关.
2. 更新板子内部的rknn库, [rknn-toolkit2](https://github.com/airockchip/rknn-toolkit2.git).
3. 部署rga库方便图像转换, [rk_rga](https://github.com/airockchip/librga.git)
4. 配置smb
    ```bash
    sudo apt update
    sudo apt install samba samba-vfs-modules -y
    
    sudo vim /etc/samba/smb.conf
    [global]
       workgroup = WORKGROUP
       security = user
       map to guest = never
       unix extensions = no
       follow symlinks = yes
       wide links = yes
    
    [share]
       path = /home/radxa
       force user = radxa
       browseable = yes
       writable = yes
       create mask = 0644
       directory mask = 0755
       follow symlinks = yes
       wide links = yes
    # 保存退出
    sudo smbpasswd -a radxa
    sudo systemctl restart smbd nmbd
    sudo systemctl enable smbd nmbd
    ```
5. 配置usb
   ```shell
     sudo vim /etc/udev/rules.d/99-usb-permissions.rules
     # ElectronBot (Robot)
     SUBSYSTEM=="usb", ATTR{idVendor}=="1001", ATTR{idProduct}=="8023", MODE="0666", GROUP="plugdev"
   
     # USB 摄像头
     SUBSYSTEM=="usb", ATTR{idVendor}=="090c", ATTR{idProduct}=="037c", MODE="0666", GROUP="plugdev"
   
     # 串口设备
     SUBSYSTEM=="usb", ATTR{idVendor}=="10c4", ATTR{idProduct}=="ea60", MODE="0666", GROUP="plugdev"
   
     然后：
   
     # 重载规则
     sudo udevadm control --reload-rules
     sudo udevadm trigger
   
     # 把用户加入 plugdev 组
     sudo usermod -aG plugdev radxa
   ```
