# Contract: 设置页与测试页键盘/UI 契约

所有按键仍经 `input/mod.rs` → `handle_by_mode` 派发（宪法 I），本文件是
各页面处理函数的对外行为契约。

## 1. 设置页音量条

### 布局

设置列表在现有配置项中插入两行（位置：输出设备之后、TTS 相关项之前）：

```text
  输出设备: USB audio CODEC, USB Audio
▶ 扬声器音量: [██████████░░░░░]  70%
  麦克风音量: [█████░░░░░░░░░░]  35%  |电平 [███░░░░░]  22|
  TTS开关: 开
```

- 扬声器行：增益条 + 百分比
- 麦克风行：增益条 + 百分比 + 实时电平指示（`server.volume`，无采集时为 0）
- 条渲染复用 device_status.rs `render_bar` 风格（字符块填充）

### 键盘契约（音量行被选中时）

| 按键 | 行为 |
|------|------|
| `←` / `→` | 音量 −5% / +5%，clamp [0, 100]，立即回写 `SetConfig` |
| `↑` / `↓` | 移动选中行（现有行为不变） |
| `R` | 刷新设备列表（现有行为不变） |
| `Esc` | 退出设置页（现有行为不变） |

音量行**无编辑态**：`Enter` 在音量行无操作（不进入 EditField overlay）。
操作说明栏在选中音量行时显示：`操作: [←→] 调节音量  [↑/↓] 选择  [Esc] 退出`

## 2. TTS/LLM 测试页输入框

### 渲染

- 光标：块字符 caret（`█` 反色高亮策略，与 settings.rs 一致；不用终端原生
  光标，popup Clear 兼容原因见 settings.rs:96 注释）
- 超宽：以 caret 为中心的横向滚动窗口，caret 恒可见
- 空输入时 caret 在行首

### 键盘契约（两页共同）

| 按键 | 行为 |
|------|------|
| 可打印字符 | 插入到光标处 |
| `Backspace` | 删光标前一个 char（中文整字删除） |
| `Delete` | 删光标处一个 char |
| `←` / `→` | 光标移动一个 char |
| `Home` / `End` | 跳行首/行尾 |
| `Ctrl+U` | 一键清空 |
| `Enter` | 提交全文（空输入不提交） |
| `Esc` | 退回导航（现有行为不变，缓冲保留） |

### TTS 页保留快捷键（不冲突）

`↑`/`↓`/`+`/`-` 调速度、`M` 切流式 — 全部保留。←→ 原无绑定，现归光标。

### LLM 页保留快捷键

`F2` 清空记忆保留。←→ 原无绑定，现归光标。

## 3. 测试要求

- TextInput 单测：中文插删、光标边界（空 buffer 退格/左移无 panic）、
  Home/End、Ctrl+U 清空、before/after_cursor 切分正确性
- 设置页 viewmodel 单测：音量行存在性与显示值格式
