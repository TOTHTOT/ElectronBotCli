# Feature Specification: 设置页音量调节与测试输入框优化

**Feature Branch**: `003-volume-input-controls`

**Created**: 2026-08-09

**Status**: Draft

**Input**: User description: "设置内增加麦克风 扬声器音量条功能 tts和llm测试的输入框优化一下 目前不支持删除, 最好改成内置的输入框"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 设置页调节扬声器与麦克风音量 (Priority: P1)

用户打开客户端的设置页，可以看到「扬声器音量」和「麦克风音量」两个音量条。用键盘（左右方向键）即可调高/调低音量，调节立即在机器人端生效：扬声器音量影响机器人播放声音的大小，麦克风音量影响机器人采集声音的增益。音量值在客户端重启、机器人重启后保持，不需要每次重调。

**Why this priority**: 音量是音频设备最基本的使用诉求。目前机器人扬声器/麦克风音量完全不可调，播放太吵或采集太小声时用户没有任何手段，只能忍受。这是本特性被提出的直接原因。

**Independent Test**: 进入设置页，分别拖动两个音量条，机器人端播放 TTS 可感知音量变化、说话采集电平可感知变化；重启客户端与机器人后音量值保持。

**Acceptance Scenarios**:

1. **Given** 用户在设置页，**When** 选中扬声器音量条并按右方向键，**Then** 音量值增大并立即在机器人端生效，界面实时显示当前值（百分比）
2. **Given** 用户在设置页，**When** 选中麦克风音量条并按左方向键，**Then** 采集增益减小并立即生效，音量条同时实时显示当前输入电平，界面显示当前增益百分比
3. **Given** 音量已调整为非默认值，**When** 重启客户端并重新连接机器人，**Then** 设置页显示的音量值与调整后的值一致
4. **Given** 音量已调整为非默认值，**When** 机器人服务端重启，**Then** 音量保持在调整后的值

---

### User Story 2 - TTS/LLM 测试输入框支持完整编辑 (Priority: P2)

用户在 TTS 测试页和 LLM 测试页输入文本时，输入框是一个可见的、行为符合直觉的编辑控件：可以退格删除、可以用方向键移动光标、可以在文本中间插入和删除字符、可以一键清空。输入内容始终完整可见（超长时横向滚动跟随光标），光标位置有明确视觉指示。

**Why this priority**: 目前测试输入框只能追加字符、无法正常删除，输错一个字只能整段重来，测试体验很差。但它不阻塞机器人的核心功能，排在音量调节之后。

**Independent Test**: 在 TTS/LLM 测试页输入一段文字，执行退格、光标左移后插入、光标左移后删除、清空等操作，显示内容与光标行为与常见输入框一致。

**Acceptance Scenarios**:

1. **Given** 输入框已有文本「你好世界」，**When** 按退格键，**Then** 删除光标前一个字（对多字节字符删除整个字符而非半个）
2. **Given** 输入框已有文本，**When** 按左/右方向键移动光标后输入字符，**Then** 新字符插入到光标位置而非末尾
3. **Given** 输入框已有文本，**When** 光标在行中间按退格/Delete，**Then** 删除光标前/后对应位置的字符
4. **Given** 输入框文本超过显示宽度，**When** 继续输入或移动光标，**Then** 视图横向滚动保持光标可见
5. **Given** 用户在 TTS 或 LLM 测试页，**When** 按回车提交，**Then** 发送当前完整文本，原有快捷键（速度调节、流式切换、清空记忆等）不受影响

---

### Edge Cases

- 音量调到 0%（静音）和 100% 时继续按方向键，值停留在边界不溢出
- 机器人端音频设备切换（换声卡）后，音量设置仍然应用到新设备上；若应用失败，界面给出可见提示而非静默无效
- 输入框为空时按退格/Delete/左移，无任何异常
- 输入框包含 emoji 等多字节/组合字符时，删除与光标移动按字符（grapheme）而非字节工作
- 音量调节请求发出时机器人连接断开，界面提示失败，本地显示值不与实际状态脱节

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 设置页 MUST 展示扬声器音量条与麦克风音量条，各自显示当前音量百分比
- **FR-002**: 用户 MUST 能用键盘在两个音量条上增大/减小音量，调节步进可见（默认 5%），范围 0%–100%
- **FR-003**: 扬声器音量调节 MUST 实时作用于机器人端所有音频播放（TTS、提示音等）
- **FR-004**: 麦克风音量条 MUST 同时支持采集增益调节与实时输入电平显示：用户可调增益百分比，音量条上实时反映当前采集到的声音大小，调节后能立刻看到效果
- **FR-005**: 两个音量值 MUST 持久化，客户端重启与机器人服务端重启后保持
- **FR-006**: 客户端与机器人之间的音量相关通信 MUST 遵循协议只增不改原则，旧版本客户端/服务端交叉工作时不出错（新增消息对未知端降级为无操作）
- **FR-007**: TTS 测试页与 LLM 测试页的输入框 MUST 支持：退格删除、Delete 删除、光标左右移动、光标处插入、一键清空
- **FR-008**: 输入框 MUST 按字符（含中文等多字节字符）正确删除与移动光标，不产生乱码或半个字符
- **FR-009**: 输入框 MUST 有可见光标指示，文本超宽时横向滚动跟随光标
- **FR-010**: 输入框改造 MUST NOT 破坏两测试页既有快捷键（TTS 页速度 +/-、流式切换 M、LLM 页 F2 清空记忆）与回车提交行为
- **FR-011**: 音量应用失败（设备切换、连接断开等）时 MUST 在界面给出可见反馈

### Key Entities *(include if feature involves data)*

- **音量设置**: 扬声器音量（0–100）、麦克风音量（0–100），持久化于机器人服务端配置，客户端连接时同步显示
- **测试输入状态**: 输入文本、光标位置；随页面存活，不持久化

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户在设置页 10 秒内完成一次音量调节并听到/看到效果（播放音量变化或采集电平变化）
- **SC-002**: 音量值在客户端与机器人双双重启后 100% 保持
- **SC-003**: 测试输入框支持退格/光标移动/中间插入删除，输错修正不再需要整段重输，单次修正操作 ≤ 3 次按键
- **SC-004**: 含中文的输入文本删除与光标移动无乱码、无半个字符残留
- **SC-005**: 旧版本客户端连接新版本服务端（及反向）时，音量相关功能静默降级，其余功能不受影响

## Assumptions

- 音量调节作用于机器人（服务端）侧，因为发声与采集硬件在机器人上；客户端只是控制入口
- 音量值持久化在服务端现有配置文件机制中，客户端不单独保存副本
- 音量条默认值：扬声器 100%、麦克风 100%（即不改动现有行为，只有用户主动调节才变化）
- 测试输入框不持久化内容，离开页面后保留与否维持现状（当前为保留）
- 协议新增音量消息按宪法 IV「只增不改」执行，不要求新旧版本音量功能互通，只要求不出错
